# Referências e Recursos

## Arquitetura e domínio

- FOWLER, Martin. *Patterns of Enterprise Application Architecture*.
- EVANS, Eric. *Domain-Driven Design*.
- NEWMAN, Sam. *Building Microservices*.
- RICHARDSON, Chris. *Microservices Patterns*.
- HOHPE, Gregor; WOOLF, Bobby. *Enterprise Integration Patterns*.
- Documentação oficial do C4 Model e catálogo de padrões de Martin Fowler.

## Plataforma e dados

- Documentações oficiais de NestJS, Node.js, TypeScript e OpenAPI.
- Documentações oficiais de PostgreSQL, MongoDB e do ORM adotado.
- Documentações oficiais de Docker e do broker de mensagens adotado.

## Segurança, operação e governança

- OWASP Application Security Verification Standard e OWASP API Security.
- OpenTelemetry: logs, métricas e rastreamento distribuído.
- NIST: princípios de identidade e segurança aplicáveis.
- Lei nº 13.709/2018 — Lei Geral de Proteção de Dados Pessoais (LGPD).

> Versões de ferramentas e serviços devem ser verificadas em suas
> documentações oficiais no momento de cada aula.
