# Desenvolvimento de Sistemas Corporativos

Material didático da disciplina de **Desenvolvimento de Sistemas Corporativos**
do curso de Tecnologia em Sistemas para Internet (TSI). A disciplina continua a
trilha de [Desenvolvimento Web Backend](https://github.com/luciano-alexandre/desen-web-backend):
parte dos fundamentos já estudados e evolui uma API NestJS para um sistema
corporativo distribuído, seguro, integrável, observável e implantável.

## Estrutura do repositório

- `docs/`: plano, ementa, cronograma, avaliação, referências e encontros;
- `unidades/`: detalhamento das duas unidades;
- `aulas/`: modelo para encontros de 90 minutos;
- `praticas/`: orientações das três atividades práticas;
- `atividades/`: roteiro do seminário;
- `projetos/`: especificação do projeto final.


## Avaliação

- atividades práticas em sala: **30 pontos**;
- seminário: **20 pontos**;
- projeto final: **50 pontos**.

Total: **100 pontos**.
